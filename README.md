# 接触网几何检测回放与三维核查系统

浏览器端的接触网导高 / 拉出值检测数据对齐、三维回放、超限与维修闭环、趋势对比系统。
**TypeScript + React + Vite + three.js + IndexedDB(Dexie)**，纯前端、数据不出本机。

## 快速开始

```bash
npm install
npm run dev          # http://127.0.0.1:5173
```

首次打开会自动在 IndexedDB 播种一套完整演示数据：**云岭线 K0–K50 双线、8 条曲线、4 座隧道、3 个月（2026-09/10/11）× 上/下行共 6 个检测 run**，并人为植入尺度漂移、平滑游走、里程跳变、检测主机大负跳变（重置）与数据断点。

其它命令：

```bash
npm run build         # 生产构建到 dist/
npm run preview       # 预览生产包
npm run typecheck     # tsc 类型检查
npm run check:align   # 里程对齐精度自检（断言 < 0.5m）
npm run check:csv     # “导出漂移 CSV → 解析 → 对齐”往返自检
```

## 最关键：里程对齐如何保证 < 0.5m

实现在 `src/core/alignment.ts`，以线路档案支柱里程为权威：

1. **杆号匹配**：CSV 过杆记录的杆号 ↔ 档案支柱（归一化 + 尾号兜底），得到 `(漂移里程 raw → 档案里程 ref)` 锚点；重复 / 未知 / 漏杆分别标记。
2. **跳变识别**：相邻锚点的 raw 跨距与档案跨距之差 > 1.5m 判为里程跳变，并在采样流中定位到具体行。
3. **断点 / 重置识别**：扫描采样里程增量，识别大缺口（数据断点）、负跳变与非单调（主机重置）。
4. **分段稳健修正**：在所有跳变 / 断点处切分段；段内对偏差 `ref - raw` 做 tricube 局部线性加权平滑（压制过杆噪声），再构造分段线性 `raw → corrected` 映射，段端外推。支持整体偏移 / 系数与逐跳变启用 / 忽略的人工修正后重算并重判超限。
5. **留一杆交叉验证（LOOCV）**：每根支柱用前后邻杆预测并与档案里程比较，量化“对齐后支柱位置 vs 档案”的真实误差。

演示数据实测（`npm run check:align`）：

```
全局最大留一杆误差 : 0.221 m  (< 0.5 m)
全局最大真值误差   : 0.164 m  (种子数据带 truthMileage，全采样点校验)
CSV 往返最大误差   : 0.200 m  (npm run check:csv)
```

检测批次页每个 run 都有绿色 `< 0.5m 达标` 仪表，“对齐详情/修正”里可查逐杆残差、跳变量、断点说明、分段系数。

> 导入真实 CSV 时请保留「里程」与「杆号」两列；过杆行的里程建议使用过杆事件自身的亚米级里程（系统导出的演示 CSV 即如此）。

## 功能与页面

| 页面 | 能力 |
| --- | --- |
| **检测批次** | 导入检测车 CSV（中英文表头、`K12+345.6` 里程格式自适应）；下载含漂移演示 CSV / 模板；批次×线别对齐质量总表；对齐详情、逐杆残差、人工偏移/系数/跳变开关并重算 |
| **线路档案** | 支柱位置/侧别/跨距（改里程自动重算）、锚段与补偿张力、曲线半径/方向、隧道、定位器设计拉出值、吊弦位置的增删改查；**锚段几何图**（导高+拉出双曲线、限界线、支柱/吊弦标注），可导单锚段 SVG 或一键导出全部锚段 HTML 图册（浏览器打印为 PDF） |
| **三维回放** | three.js 按实测导高/拉出值重建接触线、承力索（抛物线弛度）、吊弦与定位器；设计之字线；支柱/腕臂、双轨与轨枕带、曲线平面积分、透明隧道；检测车 + 受电弓 + 实时弓网接触点；垂直/横向独立放大（偏差放大、非真实比例）；播放/倍速/拖拽；HUD 实时里程、杆号、导高、拉出值、车速、预警 |
| **超限管理** | 导高偏差与拉出值按可配置限界自动判一/二级，连续超限采样聚类成“超限点”；批次/线别/等级/项目/状态筛选；勾选生成工单；导出超限报表 CSV（带 BOM，Excel 中文不乱码）；三维定位跨页精确跳转 |
| **维修工单** | 超限点派单、工区、计划天窗、措施/结果登记；提交后自动寻找完成日期之后最早的同线别检测 run，在 `±12m` 窗口比较异常分量降幅并判定是否修好；可随时“重新核对” |
| **趋势对比** | 同锚段/区段三个月曲线叠加 + 一/二级限界线；按定位支柱提取三月测值，筛选连续两月同向且绝对值持续增大的点并按恶化量排行（含迷你趋势线）；点击行联动三维 |
| **设置** | 四级限界阈值、对齐承诺、复核窗口/降幅、默认放大倍数与图层开关；按新阈值重判全部超限；IndexedDB 用量与一键清空重播 |

```
    db.ts          Dexie/IndexedDB、播种、导入、派单、复核、重判
  three/

```

## 技术说明

- 大体量采样（6 run × 约 5 万点）以 `Float64Array/Float32Array` 存于 IndexedDB，读取后直接喂给几何与 Canvas，不做逐点响应式。
- 里程图按像素列 min/max 包络抽稀，50km 全量也能流畅绘制与拖拽。
- 支柱在 Dexie 中按字符串主键存储，读取顺序可能是 `S1,S10,S100…`；三维与对齐逻辑均在入口统一按里程排序，避免乱序连线。
- 三维使用低边数扫掠圆管（自带稳定标架，无 Catmull 过冲），承力索按锚段合并以减少 draw call；轨枕使用 Mipmap 贴图带而非十多万实例，避免斜视摩尔纹。
