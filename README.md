# 接触网几何检测回放与三维核查系统

浏览器端接触网（OCS）几何检测数据回放、里程对齐、三维可视化与超限闭环管理系统。
TypeScript + three.js + IndexedDB，纯前端、无需后端，检测数据本地持久化。

## 功能模块

| 页面 | 能力 |
|------|------|
| **三维回放** | 按实测导高/拉出值重建接触线与承力索；受电弓沿线走行、弓网接触点实时追踪；导高/拉出毫米偏差独立放大显示；自由/跟随/俯视三种相机；超限点三维标注与点击定位 |
| **检测批次** | 导入检测车 CSV；按杆号锚点自动识别里程漂移/跳变/断点并保形修正；对齐前后偏移曲线、锚点残差、问题清单可视化 |
| **线路档案** | 支柱/跨距/锚段/平曲线/隧道/定位器/吊弦档案，方向与锚段筛选 |
| **超限管理** | 按限界自动判一级/二级；连续超限合并取最恶劣点；里程分布图联动三维；超限点生成维修工单，下批次自动复核闭环；导出超限报表 |
| **趋势对比** | 同一区段多月曲线叠加；定位点级持续变化排名，识别单调劣化 |
| **设置** | 限界值、三维放大系数配置；锚段几何图导出；演示数据重建/清空 |

## 里程对齐（核心）

检测车里程轮存在磨耗漂移、换端跳变、人工校正重置、采集中断断点。算法：

1. **杆号锚点匹配**——CSV 杆号标记与档案支柱匹配，得到 `rawMileage → profileMileage` 控制点；
2. **偏移阶跃分段**——对锚点偏移量 `raw − profile` 做差分，阶跃 >3m 判定跳变/重置，自动切物理段；
3. **raw 空档断点**——原始里程空档 >100m 判定采集断点，两侧独立成段、不插值伪造；
4. **局部离群剔除 + 单调 PCHIP**——段内校正曲线直接穿过锚点（保形三次插值、极值点防过冲），锚点零残差；
5. **确定性段归属**——采样按 raw 顺序扫描，仅在进入新段锚点范围时切换，跳变重叠区保持原段；
6. **低置信标记**——跳变 ±60m、断点 ±150m 过渡带标记 `lowConfidence`，不参与超限判定。

**验收结果**（`npm run test:align`）：

- 支柱定位点（杆号锚点级）对齐残差 **最大 0.000m，全部 < 0.5m** ✅
- 正常区段逐采样点 P50=0.22m / P95=0.63m / Max=1.55m
- 跳变/断点过渡带单独标记，不污染超限判定

## 演示数据

内置生成器（`src/lib/`）构造一条 50km 双线：

- 8 处平曲线（R1200~3500m）、4 座隧道、约 23 锚段/方向、1900+ 支柱、跨距 40~60m；
- 三个月 × 上下行共 6 个检测批次，0.25m 采样；
- 预埋里程问题：0~28km 缓漂移（末端 +18m）、K28 −12m 跳变、K36 人工重置、K41.2~41.8 采集断点；
- 预埋缺陷：持续下沉/抬升定位点（趋势用）、导高与拉出超限点、按月修复/持续缺陷（工单闭环用）。

## 常用命令

```bash
npm install
npm run dev          # 启动开发服务器
npm run build        # 类型检查 + 生产构建
npm run test:align   # 里程对齐精度验证（0.5m 验收）
npm run test:business # 趋势/工单复核/断点/低置信业务闭环验证
npm test             # 全部验证
```

启动后点击左下角「载入内置演示数据」，约 1 分钟完成 6 批次生成、对齐、超限判定与入库。

## CSV 格式

```
里程(m),杆号,导高(mm),拉出值(mm),隧道标记
100.00,1#,6002,15,0
100.25,,6001,16,0
```

杆号列在检测车过杆时填写，是里程对齐的锚点来源；可在批次页下载模板。

## 技术要点

- **存储**：IndexedDB 五张对象库（档案/批次/采样/超限/工单），复合键 + 批次索引；采样落库前重采样到 1m 网格控制体量，超限判定仍在 0.25m 全分辨率内存数据上完成。
- **三维**：three.js 中心线逐米积分（曲线段曲率拼装），高细节窗口（±600m，0.5m 步长）随受电弓移动重建，全局粗模（10m 步长）保走向，兼顾精度与性能。
- **可视化口径**：导高偏差相对设计曲线（含跨中弛度）评估，拉出值按弓网安全绝对包络评估，避免把正常弛度/之字形误判为超限。
