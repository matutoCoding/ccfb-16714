# 接触网几何检测回放与三维核查系统

供电段接触网检测车数据的浏览器端回放、里程对齐与三维核查工作台。
TypeScript + Vue 3 + three.js + IndexedDB，纯前端运行，无需后端服务。

## 功能模块

| 模块 | 能力 |
| --- | --- |
| 检测批次 | 导入检测车 CSV（中英文表头兼容）、里程对齐、断点/跳变识别、对齐验收报告 |
| 线路档案 | 支柱/定位器、跨距、锚段、曲线半径、隧道、吊弦布置台账 |
| 三维回放 | 实测导高/拉出重建接触线与承力索、受电弓走行、弓网接触点、偏差放大显示 |
| 超限管理 | 按限界自动判一级/二级、连续超限合并区段、三维定位、派单/忽略 |
| 趋势对比 | 同股道多月份曲线叠加、定位点变化排名、持续单调变化自动高亮 |
| 维修工单 | 处理结果登记、新批次同里程自动复核闭环 |
| 设置 | 限界阈值、放大倍数/回放速度、超限 CSV 与锚段几何 PNG 导出、数据管理 |

## 快速开始

```bash
pnpm install
pnpm gen:data     # 生成样例数据到 public/sample-data（已随仓库生成，可重跑）
pnpm dev
```

浏览器打开后，在「检测批次」页点击 **一键载入样例数据**：
示范线 50km 双线、2002 根支柱、168 个锚段、3 条曲线、3 座隧道，
以及 6 个检测批次（双线 × 三个月，含渐变/跳变/周期三类里程漂移与断点重计）。

## 里程对齐算法（核心）

见 `src/core/align.ts`，流程：

1. **事件识别**：检测车 `BREAK` 事件与相邻采样里程突变，切分断点段；
   相邻 delta 超过标称采样间隔 8 倍标记为里程跳变。
2. **杆号锚点匹配**：过杆事件（`POLE` + 杆号）匹配线路档案支柱，
   得到每个锚点的漂移量 `offset = 档案里程 - 原始里程`。
3. **分段线性校正**：断点之间按锚点漂移量线性插值，
   杆号位置精确落回档案里程，非杆号采样保持局部里程比例不失真。
4. **验收**：输出全部锚点残差，`maxResidualM < 0.5m` 判定通过。

样例数据验收结果（`pnpm gen:data` 后运行 `node scripts/verify_align.mjs`）：
6 个批次最大杆位残差均为 `0.0000m`，真实漂移量 3.6~5.3m，全部通过 0.5m 验收。

`node scripts/verify_exceeds.mjs` 可端到端复核超限判定，
样例数据共注入 5 类缺陷场景（导高下沉恶化、拉出持续偏移、导高越上限、隧道内导高过低、孤立拉出超限），
覆盖一级/二级判定与工单修复闭环叙事。

## 目录结构

```
scripts/                 零依赖 Node 样例数据生成与对齐验证
public/sample-data/      生成的线路档案 JSON + 6 个检测 CSV
src/core/                对齐、超限判定、趋势、复核、导出、CSV 导入
src/three/scene.ts       three.js 三维场景（接触线/承力索/吊弦/受电弓/隧道）
src/db/idb.ts            IndexedDB 封装
src/pages/               7 个业务页面
src/components/          Canvas 里程图、线框图标、空状态
```

## 数据与存储

- 全部业务数据存浏览器 IndexedDB（库名 `ocws_db`），采样点按批次整条存储。
- CSV 必需列：序号、原始里程、导高、拉出值；可选列：事件（POLE/BREAK）、杆号。
- 清空数据：设置页「清空全部本地数据」。
